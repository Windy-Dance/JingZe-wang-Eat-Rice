# JingZe-wang-Eat-Rice

王境泽吃炒饭的 pygame 小游戏：控制王境泽移动去吃炒饭，每吃 10 分多出 3 碗炒饭。

## 运行

```bash
pip install pygame
python JingZewangEatRiceV1.0/Eating.py
```

## 操作

- `W` / `↑` 上移
- `S` / `↓` 下移
- `A` / `←` 左移
- `D` / `→` 右移
